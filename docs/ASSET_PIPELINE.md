# FaceIt — Artwork Import and Asset Pipeline
## Rules
No hotlinked web images in production. No bundled images without ownership, licence or documented permission. Preserve creator, source, licence, attribution and provenance. Sacred-site content receives accuracy and respect review.
## Asset metadata
Stable ID, title, category, tags, dimensions, file path, creator, licence, attribution, provenance, SHA-256 and review status.
## Build validation
Reject missing files, duplicate IDs, invalid dimensions, missing licence/provenance and hash mismatch. Generate thumbnails and previews while retaining original PNGs.
## Current status
The initial native app includes a procedural offline wallpaper renderer. The 100-image curated photographic PNG collection is a separate content-production gate and is not claimed to be present until actual assets and manifest are committed.
