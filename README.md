# FaceIt

**Personalise Your World.**

FaceIt is a global, offline-first mobile personalisation platform by ZamCan. It lets people compose their own visual environments from independent backgrounds, objects, materials, lighting, motion, widgets, icons and supported phone-interface experiences.

## Product principles

- **Compose, don't impose:** users combine independent visual layers; no fixed category-bound themes.
- **User-controlled:** each personalisation feature is optional, independently enabled and reversible.
- **Offline-first:** useful core functionality and an initial library of at least 100 high-quality PNG wallpapers are included on-device.
- **Resource-aware:** inactive features do not run unnecessary services, animations or rendering engines.
- **Real functionality:** previews, controls and integrations must work; no decorative controls pretending to be functional.
- **Privacy-first:** local processing by default, especially for keyboard and private content.
- **Respectful content:** Islamic cities, sacred architecture and Islamic visual heritage are the first priority for religious and cultural collections.
- **Platform honesty:** Android system integrations must use supported APIs, roles and user-granted permissions.

## Signature capabilities

1. Personal Visual Environment composition engine.
2. Wallpaper and offline artwork library.
3. Theme and supported app-icon personalisation.
4. Home-screen widget studio.
5. **Phone Dialer Keypad Studio** — custom number-pad appearance and, where supported, a genuine dialer experience. This is not the text-entry keyboard.
6. Optional text-entry keyboard personalisation as a separate feature.
7. On-demand interactive 3D object studio.
8. Secure local Vault.
9. Adaptive Resource Engine.

## Initial content direction

Islamic cities and architecture lead the cultural collection. Other visual universes include football, health and medicine, engineering, law, programming, finance, science, automotive, fashion, wildlife, nature, geometry, abstract art and world cities. Additional religious and cultural collections can be added in later updates.

## Technology direction

The proposed first platform is native Android using Kotlin and Jetpack Compose, subject to architecture validation. Future iOS support must use native platform capabilities and must not be promised where platform restrictions prevent equivalent behaviour.

## Project status

Repository foundation and product specification. No production feature should be considered complete until it has working behaviour, tests and real-device validation.
